# How to Create Sidebar in HTML and CSS

Um projeto simples de **sidebar (menu lateral)** usando HTML e CSS.

## ✨ Sobre

Este projeto mostra como criar uma **barra lateral responsiva** para navegação em sites.

## 🛠️ Tecnologias

- HTML
- CSS

## 🎯 Funcionalidades

- Menu lateral fixo
- Layout organizado
- Fácil de personalizar

## 🚀 Como usar

1. Baixe ou clone o repositório  
2. Abra o arquivo `index.html` no navegador
